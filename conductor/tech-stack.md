# Tech Stack

## Backend
-   **Language & Framework:** Java 21 with Spring Boot
-   **AI Integration:** Spring AI (Google GenAI, Ollama)
-   **Security:** Spring Security
-   **Data Persistence:** Spring Data JPA, H2 Database
-   **API Documentation:** OpenAPI (springdoc)

## Frontend
-   **Language & Framework:** TypeScript with Angular (v21)
-   **UI Library:** PrimeNG, PrimeIcons
-   **Styling:** Tailwind CSS, PrimeUIX themes

## Build Tools
-   **Backend Build:** Maven
-   **Frontend Build:** npm (managed via `frontend-maven-plugin`)
